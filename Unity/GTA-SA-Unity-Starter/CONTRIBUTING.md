# Contributing to BudgieOS GTA-SA Unity Starter

Thanks for your interest in contributing!

## Ways to help
- Fix bugs in the C# scripts.
- Improve player movement, camera behavior, or arcade vehicle handling.
- Add original test scenes, UI, or 3D assets.
- Improve build instructions and documentation.
- Test the project with supported Unity versions and report reproducible issues.

## Before submitting
1. Check existing issues and pull requests to avoid duplicate work.
2. Keep changes focused and explain why they are useful.
3. Use clear C# names and add comments where behavior is not obvious.
4. Test in Unity when possible. Include the Unity version and relevant Console output when reporting a build issue.
5. Do not commit generated folders such as `Library/`, `Temp/`, `Obj/`, or local build output.

## Pull request process
1. Fork the repository.
2. Create a branch with a descriptive name, for example `fix/vehicle-steering`.
3. Commit your changes with a clear message.
4. Push the branch to your fork.
5. Open a Pull Request describing the change, how it was tested, and any limitations.

## Asset and copyright rules
Contribute only code, models, textures, audio, and other assets that you created or are authorized to redistribute. Do not upload the original GTA: San Andreas game, extracted Rockstar assets, game executables, or copyrighted game content.

## Questions and bug reports
Use GitHub Issues in the main repository. Include steps to reproduce, expected behavior, actual behavior, Unity version, and relevant error messages. Never include passwords, access tokens, or other secrets in an issue.
